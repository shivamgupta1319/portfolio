### 🧩 This repo (shivamgupta.live)

Next.js 16 static export, deployed on Netlify.

- `/` — profile page (server-rendered, indexable). `/desktop/` — the game-OS "Desktop mode" (noindex).
- `npm run dev` · `npm run build` (prebuild refreshes `src/data/quests.generated.json` from GitHub when a token / `gh` login is available)
- `npm run shots` — capture project covers into `public/shots/` with the local Chrome (see `scripts/shots.config.json`)
- `npm run lint` · `npm run lint:text` (no text below 13px)
- Content lives in `src/data/*` — `quests.curated.ts` is the project catalogue.
- Optional env: `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_GOOGLE_VERIFICATION`, `NEXT_PUBLIC_ANALYTICS_PROVIDER` (`umami` | `plausible`), `NEXT_PUBLIC_ANALYTICS_SRC`, `NEXT_PUBLIC_ANALYTICS_ID`.
